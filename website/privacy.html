Privacy

What this project stores

The website stores only a theme preference in localStorage (mst-theme). Maurya Desktop stores the same preference locally.

There is no user account system, no analytics SDK, and no server-side contact inbox in v1.0.0. GitHub will process downloads when you use Releases.

Contact form values stay in the browser unless you later connect a backend of your choosing.
